# 🍽️ NextMeal

An AI-assisted meal planning and inventory management platform designed to help users organize ingredients, discover recipes, and reduce food waste through intelligent meal recommendations.

> 🚧 This project was for final project of Master's degree.

---

# 📖 Overview

NextMeal is a full-stack web application that enables users to manage their kitchen inventory, browse recipes, save favorites, and receive personalized meal suggestions based on available ingredients.

The project is being developed with a modern React/Next.js frontend and a scalable backend architecture, following best practices for maintainability and future expansion.

---

# ✨ Features

### User Management
- Secure user authentication
- User profile management
- Personalized experience

### Inventory Management
- Add ingredients
- Edit ingredients

### Recipes
- Browse recipes
- View recipe details
- Save favorite recipes
- Search recipes

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/sabah-bsrt/NextMeal.git
```

---

## Frontend

```bash
cd nextmeal-ui
npm install
npm run dev
```

The application will start on:

```
http://localhost:3000
```

---

## Backend

```bash
cd NextMeal
npm install
npm run dev
```
